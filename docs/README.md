# Trader++ Documentation

Welcome to the comprehensive documentation for **Trader++**, a modular, realistic, and hackable trading engine for strategy backtesting and portfolio simulation.

## 📚 Documentation Structure

This documentation is organized into logical sections to help you understand and use Trader++ effectively:

### 1. [Overview & Architecture](./01-overview-architecture.md)
High-level system design, core principles, and architectural patterns that make Trader++ unique.

### 2. [Getting Started](./02-getting-started.md)
Installation, configuration, and your first backtest. Perfect for new users.

### 3. [Core Components](./03-core-components.md)
Deep dive into the core engine: Backtester, MarketData, and DataLoader.

### 4. [Contracts & Data Models](./04-contracts.md)
Understanding the fundamental data structures: Portfolio, Asset, Order, and their relationships.

### 5. [Strategy Development](./05-strategies.md)
Complete guide to creating custom trading strategies with examples and best practices.

### 6. [Execution Engines](./06-executors.md)
How BacktestExecutor, PaperExecutor, and LiveExecutor work and when to use each.

### 7. [Risk Management & Guardrails](./07-guardrails.md)
Implementing risk controls and protective mechanisms for your strategies.

### 8. [Data Ingestion & Sources](./08-data-ingestion.md)
Working with market data from Yahoo Finance, Alpaca, Polygon, and custom sources.

### 9. [Analytics & Performance](./09-analytics.md)
Evaluating strategy performance with metrics, benchmarks, and visualizations.

### 10. [Advanced Topics](./10-advanced-topics.md)
Multi-asset strategies, derivatives, portfolio optimization, and ML integration.

### 11. [API Reference](./11-api-reference.md)
Complete API documentation for all classes, methods, and functions.

### 12. [Examples & Tutorials](./12-examples.md)
Practical examples and step-by-step tutorials for common use cases.
